# Contributing

Thanks for helping improve the **mac-duo** organization meta-repository.

## Code of Conduct

Participation means agreeing to [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

## Local setup

```bash
git clone https://github.com/mac-duo/.github.git
cd .github
```

## Pull requests

1. Branch from `main`.
2. Keep org profile changes concise — link to app repos for detail.
3. Open a PR using the repository pull request template.
