<h3>MacDUO</h3>
<p><strong>MacDUO</strong> is a native <strong>SwiftUI</strong> macOS app that recreates the iPhone <strong>Duo</strong> closing animation on your MacBook screen — a satisfying fold-away effect across the display.</p>
</div>

<br/><br/>

<div align="center">

</div>

<hr>

### Features

| | |
|---|---|
| **Duo closing animation** | Fold-away motion inspired by iPhone Duo |
| **Full-screen canvas** | Animation plays across the MacBook display |
| **Native macOS** | SwiftUI app — lightweight and on-device |
