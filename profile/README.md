# MacDUO

**iPhone Duo closing animation on your MacBook.**

A native **SwiftUI** macOS app that recreates the iPhone **Duo** fold-away closing animation on the MacBook display.

**MacDUO** brings the satisfying Duo-style closing fold to macOS — full-screen motion on your MacBook, built for Mac App Store distribution. No account required for the core experience.

### Features

| | |
|---|---|
| **Duo closing animation** | Fold-away motion inspired by iPhone Duo |
| **Full-screen canvas** | Animation plays across the MacBook display |
| **Native macOS** | SwiftUI app — lightweight and on-device |
