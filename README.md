# .github

Organization meta-repository for [**mac-duo**](https://github.com/mac-duo) — governance, automation, and the public org profile for **MacDUO**.

**MacDUO** is a macOS app that emulates the iPhone Duo closing animation on the MacBook screen.

## Organization profile

The visitor-facing page at [github.com/mac-duo](https://github.com/mac-duo) is rendered from [`profile/README.md`](profile/README.md).
